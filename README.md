## Устройство

- `public/` — статика без сборки (сейчас — страница-заглушка).
- `server.mjs` — локальный сервер для проверки.
- `vercel.json` — настройки Vercel, `.github/workflows/pages.yml` — публикация демо.

## Локально

```bash
node server.mjs
```

Сайт откроется на http://localhost:5250.
